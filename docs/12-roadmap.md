# 12. ロードマップ

## 1. v1：基本機能とセルフホスト可能な構成（このドキュメントのスコープ）

機能：
- Email + パスワード + TOTP 2FA
- ファイルアップロード（tus.io）/ ダウンロード / プレビュー
- フォルダ階層 / リネーム / 移動
- ソフト削除 30 日 + バージョン履歴
- OCC + コンフリクトコピー
- 公開リンク（期限・パスワード）
- ファイル名・タグ検索
- 監査ログ / アクティビティタイムライン
- HTMX SSE による「変更通知」

インフラ：
- Docker / Terraform / ECR / ECS Fargate
- RDS for MySQL（Primary + Read Replica 1）
- S3 Files（NFS マウント）
- Cloudflare Tunnel + サイドカー nginx
- CloudWatch ログ・メトリクス

非機能：
- TLS 1.3 / HSTS / CSP
- アプリ層 AES-256-GCM + S3 SSE
- レート制限 / CSRF / XSS 対策
- WCAG 2.1 AA
- p95 < 200ms（一覧）

リリース基準：
- 全 E2E シナリオがグリーン
- DR リハーサル成功
- セキュリティスキャン Critical 違反なし
- ドキュメント揃い

## 2. v2：運用強化と利便性

候補機能（優先順）：

| 機能 | 価値 | コスト |
|---|---|---|
| お気に入り / スター | 整理性 | 低 |
| Webhook（外部通知） | 連携性 | 中 |
| 画像サムネイル生成（サーバ側） | 体感速度 | 中 |
| 動画ストリーミング再生（HLS / range request） | 体感速度 | 中 |
| 公開リンクのアクセス回数上限 | セキュリティ | 低 |
| 共有リンクの「閲覧専用 vs ダウンロード可」 | セキュリティ | 低 |
| 共有リンクへの IP 制限 | セキュリティ | 中 |
| OS ネイティブ自動同期クライアント（Go CLI） | UX | 高 |
| メールでファイル送信 | UX | 中 |
| クロスリージョン S3 レプリケーション | DR | 中 |
| ステータスページ | 可視性 | 低 |
| OpenTelemetry トレース | 観測性 | 中 |
| アプリ内メモリキャッシュ（カテゴリ・タグ） | 性能 | 低 |
| WAF（AWS Managed Rule） | セキュリティ | 中 |

リリース時期: v1 安定後 3〜6 ヶ月。

## 3. v3：拡張と省力化

| 機能 | 価値 | コスト |
|---|---|---|
| 全文検索（PDF / OCR / 画像内文字） | 探索性 | 高 |
| ファイル内容の差分表示（テキスト） | UX | 中 |
| バージョン間 diff（Office 文書も） | UX | 高 |
| 共有リンクから「Drop-off アップロード」（他人が自分宛にアップロード） | UX | 中 |
| Passkey / WebAuthn | セキュリティ | 中 |
| クライアント側 E2E 暗号化（オプトイン） | プライバシー | 高 |
| 複数ユーザ対応（共有 / 招待） | 用途拡張 | 大 |
| Slack / LINE 通知統合 | 連携性 | 中 |

リリース時期: v2 安定後、ユースケース次第。

## 4. 各バージョンの非ゴール

| 候補 | 採用しない理由 |
|---|---|
| 共同編集（Google Docs 風） | スコープが大きく、Operational Transform / CRDT が必要 |
| 完全な OS ネイティブ自動同期（Dropbox 級） | 個人用途に対し開発・保守負荷が大きい |
| マルチテナント SaaS 化 | 個人専用前提。設計の余白は残すが、商用化は別プロジェクト |
| FUSE / 仮想ドライブ | OS 別の実装が必要 |
| ブロックチェーン保管 | 過剰 |

## 5. 進化の指針

- **不変条件 INV-1〜INV-5 を v2 / v3 でも維持する**
- 新機能は必ず ADR に記録
- 「機能を増やす」より「既存機能の信頼性を上げる」が優先
- どの機能も「外しても全体が動く」ように設計（オプトイン / フィーチャーフラグ）

## 6. リリースサイクル

- v1: 設計 → 実装 → 内部テスト → 本番デプロイ
- 以降のメジャーバージョン: 6 ヶ月程度を目安
- マイナー / パッチ: 月次
